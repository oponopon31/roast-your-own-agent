# Roast Your Own Agent

A program that writes a one-line roast of my own AI agent to `entry.txt`.

Competition: https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda

## How it works

Run `node main.ts`. It writes a single roast line to `entry.txt` in the
output directory (`MAKEFUN_OUTPUT_DIR` if set, otherwise `/output` if it
exists, otherwise the current directory).
